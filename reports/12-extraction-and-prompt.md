# Day 12｜答案抽取与 prompt 敏感性实验

## 实验设置

- 模型：`Qwen/Qwen2.5-1.5B`，revision `8faed761d45a263340a0528343f099c05c9a4323`，`bfloat16`，`cuda:0`。
- 任务：GSM8K `main/test` 的前 200 题，5-shot，`batch_size=1`，seed `0,1234,1234,1234`；`lm-eval 0.4.13`，`transformers 5.17.0`。
- 原版运行：`runs/day06_qwen15_gsm8k_s5_n200/Qwen__Qwen2.5-1.5B/`。
- 提示词变体运行：`runs/day12_gsm8k_prompt_1p5b_s5_n200/Qwen__Qwen2.5-1.5B/`。
- 变体只将 `doc_to_text` 的回答提示从 `Answer:` 改为 `Answer: Let's think step by step.`；这处改动同时出现在 5 个示例和待答题中。配置见 `configs/tasks/day12_gsm8k_prompt.yaml`。

逐题脚本核对了两次运行的题号、题目、标准答案、模型参数、种子、软件版本。将变体输入中的新回答提示替换回 `Answer:` 后，200 道题的完整输入均与原版相同。因此本次对照确实只改变了提示词文本。

## 一、答案抽取对成绩的影响

原版 GSM8K 提供两个过滤器：`strict-match` 从生成文本中提取首个 `#### 数字`；`flexible-extract` 提取末尾可识别的数值。`src/day12_extraction_audit.py` 复现这两条规则，并逐题核对其输出与 `lm-eval` 日志一致。

| 指标 | 严格抽取 | 宽松抽取 |
| --- | ---: | ---: |
| 找不到答案的题数 | 2/200（1.0%） | 0/200（0%） |
| 答对题数 | 124/200 | 124/200 |
| 准确率 | 62.0% | 62.0% |

严格抽取失败的是 `doc_id=85` 和 `186`。这两题都没有生成 `####` 形式的最终答案，回答在重复计算或句子时结束。宽松规则分别提取了末尾的 `1` 和 `160`，均与标准答案 `44` 和 `5` 不同。因此改用宽松规则后，**得分变化为 0 个百分点**。

手工复核也未找到能依据原先评分约定补记为正确的最终答案。第 85 题的中间计算出现过 `44`，但回答末尾仍在重复计算，并未明确给出最终答案；不能因为中间文本碰巧含有标准答案就改判。保守的手工修正前后仍是 **124/200**。若仅作数学上的上限假设，把这两题都算对，最高可增加 `2/200=1.0` 个百分点；这**不是**实际可支持的修正结果。

## 二、提示词敏感性

| 提示词 | 严格抽取 | 宽松抽取 |
| --- | ---: | ---: |
| 原版 `Answer:` | 124/200（62.0%） | 124/200（62.0%） |
| 变体 `Answer: Let's think step by step.` | 117/200（58.5%） | 117/200（58.5%） |
| 变体减原版 | **−7 题（−3.5 个百分点）** | **−7 题（−3.5 个百分点）** |

逐题配对：105 题两次都对，64 题两次都错，12 题从错变对，19 题从对变错。例如 `doc_id=9` 的标准答案是 `460`，原版输出 `940`，变体输出 `460`；`doc_id=13` 的标准答案是 `18`，原版输出 `18`，变体输出 `53`。可见总分下降并不意味着每一道题都退步。

变体的严格抽取失败 3/200（1.5%，题号 5、102、162），宽松抽取失败 0/200；两种过滤器的正确题数同为 117。其失败回答同样缺少 `####` 最终答案，且末尾分别停在重复加法、重复叙述和未完成的价格计算中。变体分数下降不能简单归因于正则抽取失败。

这 200 道题的观察差值是 −3.5 个百分点。31 道题的对错状态发生变化，其中 12 道变好、19 道变差；配对精确检验的双侧 `p≈0.281`。本实验只用测试集前 200 题、一个模型、一个种子和一个提示词变体，不足以证明该措辞在完整 GSM8K 或其他模型上普遍更差。

## 典型错误模式与判分边界

| 模式 | 实例 | 判断 |
| --- | --- | --- |
| 缺少最终答案标记 | 原版 85、186；变体 5、102、162 | 严格正则返回 `[invalid]`，需要检查原文，不能自动认定模型本来答对。 |
| 生成重复并停在中途 | 原版 85、186；变体 102 | 尾部仍在重复解题语句，没有可靠的最终答案。 |
| 解题结果不同 | 变体 13：标准答案 18，输出 53 | 成绩变化来自生成内容；即便有完整 `####`，仍会判错。 |
| 拒绝回答或明确答非所问 | 这次抽查的例子中未确认 | 不凭空计入此类。 |

如果遇到“模型看似答对却被判错”，应先保存原始生成、抽取结果和标准答案，区分**格式错误、抽取器误判、计算错误、未完成生成**。只有在预先写清的人工复核规则下，才能改动分数，并同时报告自动分数和修正分数，避免事后挑选有利样本。
