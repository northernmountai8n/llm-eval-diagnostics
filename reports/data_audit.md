# Day 11：C-Eval 与 MMLU 数据质量检查

## 范围与方法

本次检查两个明确的四选题子集，不将结论推广到完整 C-Eval 或 MMLU：

| 数据集 | 配置 | 划分 | 样本数 |
|---|---|---|---:|
| `ceval/ceval-exam` | `computer_network` | `val` | 19 |
| `cais/mmlu` | `abstract_algebra` | `test` | 100 |

运行 `src/data_audit.py`，检查完全重复、题干近重复候选、空字段、答案合法性、答案位置分布、题干长度离群和编码字符。MMLU 的 `answer` 为从 0 开始的整数下标；脚本先映射为 A–D，再执行答案与位置检查。每项只报告，不改动原始数据。数据集未固定 Hub revision，未来若上游数据变化应重新运行。

## 自动检查结果

| 检查项 | C-Eval 计算机网络（19 题） | MMLU 抽象代数（100 题） | 计数口径 |
|---|---:|---:|---|
| 完全重复 | 0 | 0 | 题干、全部选项和答案均相同的额外样本数 |
| 近重复 | 1 | 11 | 字符 5-gram Jaccard ≥ 0.8 的候选题对数，须人工复核 |
| 缺失或空字段 | 0 | 0 | 至少一个题干、选项或答案字段缺失的样本数 |
| 答案合法性 | 0 | 0 | 答案越界或格式异常的样本数 |
| 答案位置提示 | 3 | 1 | 与四选题均匀比例 25% 相差超过 5 个百分点的位置数，并非问题题数 |
| 题干长度离群 | 1 | 0 | 按 1.5 × IQR 阈值标记的样本数，仅供复核 |
| 编码与脏字符 | 0 | 0 | 脚本所列字符规则命中的样本数 |

这些计数的单位不同，而且同一样本可能触发多项检查，不能相加为“问题题数”。各项明细和示例见 [`day11_ceval_computer_network.md`](day11_ceval_computer_network.md) 与 [`day11_mmlu_abstract_algebra.md`](day11_mmlu_abstract_algebra.md)；机器可读结果见同名 `.json`。

## 人工复核

### C-Eval

- 第 8 与 11 题的题干和正确答案相同，选项中的 `1000B` / `1000字节`、`3000B` / `3000字节` 是等价写法。它们不是原始文本完全重复，但属于 **1 对语义重复候选**；不能把自动检查的“完全重复 0”和“近重复 1”相加说成 2 对。
- 正确答案位置分布为 A 2/19、B 3/19、C 9/19、D 5/19。脚本提示 A、B、C 三个位置偏离 25% 超过 5 个百分点；19 题太少，不能据此认定系统性位置偏置。
- 第 17 题题干 118 个字符，超过此子集的 IQR 上界 100.5 个字符。它只是相对较长；尚未检查模型 tokenizer 后长度，不能声称输入被截断。

### MMLU

- 11 对“近重复”是题干字符相似的**候选对**。逐对核对题干、选项和答案后，其中 `(0,35)` 与 `(8,35)` 两对来自同一个扩域等价组：`√18=3√2`，而 `α=√2+√3` 满足 `α⁻¹=√3−√2`，三种写法可生成同一个扩域。其余 9 对改变了多项式、有限域、群的参数或判断对象，不应直接计为重复题。
- 同一等价组的 `(0,8)` 未被字符阈值检出，Jaccard 相似度约 0.740，低于 0.8。这说明字符近重复检查既会产生待排除候选，也会漏掉数学等价题；本次不能据它估计全数据集的真实重复率。
- 正确答案位置分布为 A 22/100、B 26/100、C 31/100、D 21/100。仅 C 超过脚本的 5 个百分点提示阈值；这不是系统性偏置的证明。
- 题干字符数范围 41–243，未超过本子集的 IQR 离群阈值。字符长度不能直接代表 token 长度或模型是否截断。

## 结论与局限

在这 119 条样本中，脚本未发现空字段、答案越界或原始文本完全重复。人工复核提示 C-Eval 有 1 对语义重复候选，MMLU 的近重复候选中有一个三题的数学等价组；这些发现只涉及所选两个科目。字符规则未命中不等于完全没有编码问题，答案位置提示也不等于分数已被高估。

