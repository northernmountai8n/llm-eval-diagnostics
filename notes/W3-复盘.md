## 本周验收：我能否解释这些问题？

1. **方差图的误差线是什么？**它是五个 few-shot seed 得分的样本标准差，描述示例变化下的波动；单次 `stderr` 来自该次逐题对错的抽样误差，两者不能混称。
2. **为什么分数变化不一定是模型变化？**测试题前缀、示例、prompt、chat template、评分和答案抽取都有可能改变结果。先核对这些条件，再看逐题翻转和错误类型。
3. **预训练评测的特殊性是什么？**应在同一训练谱系的 base checkpoint 上固定数据和口径，结合验证 loss/PPL 与能力题集跟踪趋势；当前三个 Qwen 模型是不同规模，不能当作连续 checkpoint。
4. **为什么 42/50 不能写成 DeepSeek 的 MMLU 榜单成绩？**只抽了 50 题，且是 0-shot API 生成单字母；本地 Qwen 实验使用另一批题和 5-shot 候选似然，模型版本也不能按权重 revision 对齐。
